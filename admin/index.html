Importar respuestas de Microsoft Forms

Selecciona la exportación completa de Excel (.xlsx) o CSV. La importación identifica cada respuesta por su Id y actualiza registros existentes, sin duplicarlos. Los documentos se protegen en Supabase; el Excel no se publica en GitHub.

Las respuestas de prueba también se importan. Puedes excluir individualmente cualquiera de ellas desde «Administrar respuestas de Forms».

Si el navegador no permite abrir XLSX, guarda una copia CSV UTF-8 desde Excel y cárgala aquí. No compartas públicamente el archivo original.
